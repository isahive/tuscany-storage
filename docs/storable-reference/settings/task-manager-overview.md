# Task Manager Overview

**Source:** https://storageunitsoftware.zendesk.com/hc/en-us/articles/19153561847319-Task-Manager-Overview
**Article ID:** 19153561847319

---

The task manager can be used to set One Time Tasks or Recurring Tasks. To mark a task complete see, Marking Tasks Complete

Tasks will appear on the dashboard as a Manager Action Item on their due date (see also; ["Dashboard Overview"](https://storageunitsoftware.zendesk.com/hc/en-us/articles/19153429429015-The-Dashboard-overview)). You get to the Task Manager by going to Dashboard > Task Manager, by clicking the uncompleted tasks on the Dashboard or by using the Task Manager button on the Task Report.

## One Time Tasks

**Create New Task:** You can create a task for today or in the future. You enter a task Name, a Description of the task and a Due Date. This is only used for one time tasks, all recurring tasks will be done under Recurring Tasks/New Recurring Task.  
  
**Due Tasks:** Shows all tasks due; today or in the past.

**Upcoming Tasks:** Shows all tasks that have been created but are not yet due.

## Recurring Tasks

Recurring Tasks can be used as a reminder for weekly or monthly tasks. Once they are created they will appear in your Due Task list when they are due; it will appear in Upcoming tasks until then.  
**New Recurring Task:** When creating a New Recurring Task you will choose:

  1. Name - a title for the task.
  2. Description - more detailed directions on what the task is (255 character limit).
  3. Next Recurring Date - this date should be the day in the future, the day you want this task to begin; if a task is created on and due today it will not create its first task until it's next due date.
  4. Recurring - how often you want the task to happen, weekly or monthly;
     1. Weekly - the task will repeat the week day you choose i.e. Monday, Tuesday, Wednesday, etc.
     2. Monthly - the task will repeat on the day of the month you choose i.e. 1st, 2nd, 3rd, 4th, etc.



## Marking Tasks Complete

Tasks will appear on the Due Tasks list on their due date and will stay on the list until they have been marked complete. To mark a task complete and remove it from your Dashboard, you will check in the red box (this will be available for any tasks that were created by a Manager).

  
The Create Print Batch tasks are created by the software (these can be turned off, see; "Print Settings"), to mark these complete; click the link (Print # document(s)) to go to the Print Batches. You must create the Print Batch to have your task marked complete (see also; "Print Batches").

These instructions can also be used to delete a task you are not planning to complete.
