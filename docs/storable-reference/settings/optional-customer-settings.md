# Optional Customer Settings

**Source:** https://storageunitsoftware.zendesk.com/hc/en-us/articles/14499863473815-Optional-Customer-Settings
**Article ID:** 14499863473815

---

Follow the instructions below to edit optional customer settings:

1\. Log in to your account

2\. Hover over **Setup** and click**Settings.**

![settings.png](https://storageunitsoftware.zendesk.com/hc/article_attachments/31266483150615)

3\. The optional customer settings are located in the **Other** section.![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/6532f58c74982009a94e7c53/file-PE2hSgbrlW.png)

4\. Check settings to enable them or uncheck them to disable them. 

You have the ability to enable or disable the following optional customer settings:

**Enable prepay for customers**

If this setting is checked, tenants will see prepayment options on the "Make a payment" page when logged in. _Please note:_ Tenants can only prepay ahead one month at a time online. If they want to prepay for more than one month, they should call the facility process the prepayment.

**Disable partial and prepayments for locked out customers**

If this setting is checked and a customer is in locked out status on any rental, they are only allowed to make a payment for the entire past due balance. No partial payments or prepayments are allowed.

**Enable USB card swiper use**

If this setting is checked, you can populate credit card numbers using a card swiper when making a payment for a customer. Any 2-track keyboard emulation card readers can be used.

**Save unpaid customer rentals**

When this setting is unchecked, a successful payment is required for rentals initiated by customers. When checked, the rental and any payment attempts will be saved, with the unit in a Pending status.

**Automatically acknowledge new rentals/reservations**

When this setting is checked, you will not see [new rentals or reservations on the dashboard](https://storageunitsoftware.zendesk.com/hc/en-us/articles/17719957723671-How-do-I-approve-a-reservation-and-move-the-customer-in-). When unchecked, new rentals will display on the dashboard until they are acknowledged.

**Enable additional deposits**

When this setting is checked, you can add an additional deposit for each Unit type with a name of your choice.

**Customers can edit profile information**

When this setting is checked, customers can edit their profile information when they [login online](https://storageunitsoftware.zendesk.com/hc/en-us/articles/19152848770583-Tenant-portal-overview).

**Customers can edit billing information**

When this setting is check, customers can edit their recurring billing information when they [login online](https://storageunitsoftware.zendesk.com/hc/en-us/articles/19152848770583-Tenant-portal-overview).

**Customers can schedule move outs**

When this setting is checked, customers can [schedule their own move outs](https://storageunitsoftware.zendesk.com/hc/en-us/articles/15454090162327-Customer-scheduled-move-outs). _NOTE:_ You can add a restriction for Move-Out Date requests. If a customer tries to move out earlier than you allow, the system will tell them they will still be billed for the following month due to insufficient notice. 

5\. Scroll to the bottom and click **Save.**
