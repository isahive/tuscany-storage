# How do I add multiple location site maps to my website?

**Source:** https://storageunitsoftware.zendesk.com/hc/en-us/articles/18061475825815-How-do-I-add-multiple-location-site-maps-to-my-website
**Article ID:** 18061475825815

---

⚠️ These instructions apply if you have more than one software account with Storable Easy but have only one website and would like all location site maps to show on the website.

1\. Log into your Storable account.

2\. Hover over the _Website_ dropdown and click **Pages**.

3\. Click **Edit** on the _Rent Storage_ line.![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5beefac004286304a71c596b/file-wxoB6FoEAb.png)

4\. Scroll down to the widgets dropdown and add a Site Map widget.![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5bc798982c7d3a04dd5bcf7e/file-YgSkkBfhpA.jpg)

5\. You will have a dropdown option to add the other locations. _You must be logged in with a multi-facility login for this dropdown to appear.![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5bc79880042863158cc78edd/file-g9G6eFR1ls.png)_
