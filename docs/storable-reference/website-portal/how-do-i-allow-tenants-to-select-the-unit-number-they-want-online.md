# How do I allow tenants to select the unit number they want online?

**Source:** https://storageunitsoftware.zendesk.com/hc/en-us/articles/19122891923479-How-do-I-allow-tenants-to-select-the-unit-number-they-want-online
**Article ID:** 19122891923479

---

You can allow tenants to select a specific unit when renting online or, you can have the system automatically select a unit for the customer. Follow the steps below to change this setting.

1\. Log in to your Storable Easy software.

2\. Hover over the **Website** tab and select **Pages**. 

![1.JPG](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5a1f4d472c7d3a272c0e101d/1.JPG)

3\. Click **Edit** next to  _Rent a Unit or Rent Storage_.

![2.png](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5a1f4d472c7d3a272c0e101e/2.png)

4\. Scroll to the bottom of the page and click **Edit** next to the  _Available Unit Types_ widget.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5a1f4d482c7d3a272c0e101f/mceclip2.png)

5\. Scroll down to the bottom of the page, and above _Unit Types_ , there will be an option to **Allow customers to select a unit**. If this is checked, the customer will be able to select a specific unit number when renting online. If unchecked, the software will automatically pick the next available unit for the customer to rent.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5a1f4d482c7d3a272c0e1020/mceclip3.png)
