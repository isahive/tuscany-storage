# How do I edit the facility address shown on my website map?

**Source:** https://storageunitsoftware.zendesk.com/hc/en-us/articles/18079278219671-How-do-I-edit-the-facility-address-shown-on-my-website-map
**Article ID:** 18079278219671

---

To change the address of your map, you'll need to go to Setup > Contact. The physical address is what the map page pulls from. Update your address on this page, and it will update your Google Map accordingly.
