# How do I change the logo on my website?

**Source:** https://storageunitsoftware.zendesk.com/hc/en-us/articles/18089076163223-How-do-I-change-the-logo-on-my-website
**Article ID:** 18089076163223

---

1\. Log in to the management software.

2\. Hover over the **Website** tab.

3\. Then the **Settings** tab. 

4\. Once you find the area called logo, click **Choose File** and then find the location of your new logo. Select the new logo file and hit "open". The last step is to scroll to the bottom of the page and click **Save**.

Your logo must be in a ".png" or ".jpg" file and must be the right size. There is no set width requirements, but the pixel size should be 650.
