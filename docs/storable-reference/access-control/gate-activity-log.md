# Gate Activity Log

**Source:** https://storageunitsoftware.zendesk.com/hc/en-us/articles/14010948711191-Gate-Activity-Log
**Article ID:** 14010948711191

---

The**Gate Activity Log** allows you to view the gate activity of the tenants at your facility. To view the log, navigate to Reports>Facility>Gate Activity Log.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5c5b655d042863543cccaa2e/file-WOxrrtvPe7.png)

**Showing activity f****rom** : With this option, you'll be able to set a date range of your search. Say you need to search a tenants gate usage for a certain month. Enter in the dates and the customers name and click **Search**.**  
**

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5c5b6387042863543cccaa18/file-alTf10WJU0.png)

Once you enter in a search date the box below will show all gate usage of those dates. You'll be able to either search through the box or download the list as a .csv to import into Excel.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5c5b64422c7d3a66e32e1a31/file-t2W6f6Yxom.png)

## GATE ACTIVITY LOG ERRORS/REPORTS

**Access Denied No Rule** : Tenant is not in a group, or they tried to use the code after hours

**Invalid Pin = ""** : Wrong code was used

**Person used App for requesting access** : Tenant used text to open
