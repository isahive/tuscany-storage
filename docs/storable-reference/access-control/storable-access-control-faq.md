# Storable Access Control: FAQ

**Source:** https://storageunitsoftware.zendesk.com/hc/en-us/articles/14010813390743-Storable-Access-Control-FAQ
**Article ID:** 14010813390743

---

Storable Access Control makes it easier than ever to manage your gate access and activity. Below is a list of frequently asked questions about our Access Control System.

**1\. Can I automatically Assign Gate Codes and how many digits will they be?**  
\- Yes! Access Codes can be automatically assigned, access codes can be 4-10 digits and generate either based on the cell phone number or generate a completely random number. The default is the last 4 of the cell phone number unless you request it to be randomized and/or more digits. 

**2\. How do I let my customers know what their access code is?**  
\- We can create a custom letter and email the customer their code. We have a placeholder in our customer templates,  _[[CUSTOMER_ACCESS_CODE]]#_ , that will pull the gate code from the customer's profile and display it in a template letter. The  _[[GATE_KEY]]_ placeholder will not work in this situation. 

**3\. Can I access an activity log to see who has entered or exited the facility?**  
\- Yes, under Setup > Gate, there is a section labeled Gate Integration, and in this section, you can click on Gate Activity Log. You can also go to your reports and find the Gate Activity Log here as well.

**4\. Does the cloud node store the access codes allowing the system to work if the internet connection is disrupted?**  
-In the case that the internet connection is interrupted, the data will remain at each controller and you will continue to have access. During the outage, however, you will not be able to make any updates to the data in the software, i.e. add/remove people/rules/credentials.

**5\. What is the warranty of the Cloud Access Control Hardware?**  
-The controllers and keypads have a three-year warranty against defects in materials and workmanship.

**6\. Will your Cloud Access Control hardware interface with my existing gate operator and/or door locking mechanism?**  
-Yes! All gate operators have the necessary input terminals required. We can also connect to 12v or 24v door locking hardware.

**7\. What if I need to assign a code to a manager or the Fire Department?**  
\- You will need to create an account for them. You do not have to rent a unit to assign a code, rather click on Gate Access and assign the desired code to the account.
