# Assigning Gate Keys/Access Codes to tenants

## Assign an access code or gate key to a unit

You have the option to assign a specific Gate Key to each unit. This gate key or code must be different for each unit. The only time Storable Easy will allow duplicate codes is when the units are rented to the same customer. When the customer moves out, the unit's gate code must be changed.

Some gate software will automatically assign gate codes to units, but for those that don't, you can assign gate codes to un-rented units by following the steps below:  
Units Tab > List View > Click On the Unit Name or Number > Edit (upper right hand corner) > Enter the new gate key in the gate key field.

_If your facility has one universal code for all customers, call us to discuss options: (888) 958-5967._

**Can customers create their own gate codes when they rent online?**

Tenants cannot make their own gate codes when they rent online. The best way to deal with this is to pre-assign gate codes to each unit. When the customer rents, the gate code associated with the unit will be sent to the customer via email (if enabled)

## Assign an access code or gate key to a tenant

You can assign a gate code to customers from their customer profile page.  
Customers Tab > All Customer > Click the customer name > On their profile, click the "Gate Access" button > Under "Access Code" You can assign a new gate code or change the existing gate code.
