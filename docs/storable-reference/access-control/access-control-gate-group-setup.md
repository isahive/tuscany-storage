# Access Control: Gate Group Setup

**Source:** https://storageunitsoftware.zendesk.com/hc/en-us/articles/14014580130071-Access-Control-Gate-Group-Setup
**Article ID:** 14014580130071

---

A Gate Group is used to control when and where a Tenant has access to your facility.

## Edit an existing Gate Group

1\. Go to your Gate Settings page under **Setup > Gate**.

2\. Click **Edit** for an access group.![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5ce5713f0428634b8559938b/file-QjaUf4zU5H.png)

From here you can change the days/hours of allowed access as well as which keypads the tenants will have access to.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5ce5804c2c7d3a6d82bdd7bd/file-LJoyxlVwIF.png)

For the software to automatically assign a gate group to a unit on new rental, navigate to the Gate Groups Page and select **Units**.![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5ce5714c2c7d3a6d82bdd684/file-YWyeXpUScW.png)

Select all units for that group and click the save button near the bottom of the page.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5ce580622c7d3a6d82bdd7bf/file-7sZzmuYl1D.png)

  
To assign customers to a Gate Group, you can select **Customers** for the Gate Group.![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5ce571552c7d3a6d82bdd685/file-4zQbQ00fSB.png)

Select the customers who should have access to the gate group and click Save. 

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5ce580a72c7d3a6d82bdd7c7/file-aEfOFeAT1z.png)

## Create a new Gate Group

On the Gate Group page, click **New Group.**![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5ce5715e0428634b8559938d/file-q6hLjBMO7V.png)

Give the group a name, select the days and hours customers in the group can access your facility, and select the gates that are included in the group. Click Save when you are done.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5ce56dc62c7d3a6d82bdd62c/file-4AHRhJBpFb.png)

**Note:** For access points with multiple keypads (keypads connected to port 2) give us a call to enable the port 2 keypad on the new gate group at 435-656-1990.
