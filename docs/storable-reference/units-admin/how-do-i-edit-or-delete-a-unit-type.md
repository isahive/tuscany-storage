# How do I edit or delete a unit type?

**Source:** https://storageunitsoftware.zendesk.com/hc/en-us/articles/14879185850135-How-do-I-edit-or-delete-a-unit-type
**Article ID:** 14879185850135

---

Follow the instructions below if you need to edit or delete a unit type.

## Edit a Unit Type

If you need to change or delete a Unit Type you've created:

1\. Navigate to **Unit Types** from the Units menu.

![1.JPG](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5a1f4d3a042863319924ded6/1.JPG)

2\. Click **Edit** at the far right of the Unit Type you would like to edit.

![3.png](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5a1f4d3b042863319924ded7/3.png)

3\. You can alter the description, reservation price, setup fee, unit price, etc. Click **Update Unit Type** when you are done making changes. If you'd like to change the unit type photo, you can choose an image from the Unit Type Photos drop down (a variety pictures depicting different size units/spaces) or upload a picture of your own by using the Custom Photo option.

## Delete a Unit Type

Note: You cannot delete a unit type if there are any units associated with the Unit Type.

1\. Hover over the**Unit** tab and select **Unit Types**.

![1.JPG](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5a1f4d3a042863319924ded6/1.JPG)

2\. Find the Unit Type you wish to delete. You will see a **Disabl****e** button in the far right column next to the Edit button.

![diable_unit.png](https://storageunitsoftware.zendesk.com/hc/article_attachments/14879377182231)  
_**_Note_ :** There must be 0 in the Units column or the disable will **not** appear._

3\. Click **Disable,** then confirm that you are sure you want to disable the Unit Type.
