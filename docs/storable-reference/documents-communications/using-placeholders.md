# Using placeholders

**Source:** https://storageunitsoftware.zendesk.com/hc/en-us/articles/18031379586071-Using-placeholders
**Article ID:** 18031379586071

---

You can insert variables or placeholders to populate data from the customer's profile in document templates. Placeholders can be used in template letters, storage agreements, and late or lien notices to fill in information that is specific to the customer, such as their name  _[[CUSTOMER_NAME]]_ , account balance  _[[BALANCE]]_ , or the auction date that is scheduled in the software  _[[AUCTION_DATE]]_. 

📖 [View a list of default placeholders](https://storageunitsoftware.zendesk.com/hc/en-us/articles/18056804817943-Default-Template-Placeholders). 

## Follow the steps below to access the templates:**  
**

1\. Log into your account.

2\. Hover over the **Email, Txt, & Print** tab.

3\. Click the **Templates** sub-tab.

![Capture128.png](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5a1f4d53042863319924def5/Capture128.png)

4\. Click the template that you would like to add the placeholder to or create a new template. 

5\. Once you have that template open, you can use the Insert placeholder menu to choose the placeholder that you would like to use, and add it to the content of your message or template. 

![Capture155.png](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5a1f4d53042863319924def6/Capture155.png)

6\. Make sure to click **Update** to save any changes. 

## Custom Placeholders**  
**

You can create your own custom fields that will populate information in a template from the customer's profile. 

Any fields that are added under Customers > Fields Settings will appear as custom placeholders when editing your templates. They will be sorted alphabetically into the "Insert placeholder" list that is accessible from the templates and storage agreements pages. Please note: **Placeholders are case sensitive.**

For more information on Field Settings or custom placeholders, please see [Custom Field Settings](https://storageunitsoftware.zendesk.com/hc/en-us/articles/14875582496151-Custom-Unit-Field-Settings).

**Note:** If a custom placeholder is ever edited/changed/updated, the placeholder in the lease agreement will need to be re-selected as it will change too. If it is not updated then the placeholder will NOT work.
