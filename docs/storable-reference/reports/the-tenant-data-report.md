# The Tenant Data Report

**Source:** https://storageunitsoftware.zendesk.com/hc/en-us/articles/18029394597783-The-Tenant-Data-Report
**Article ID:** 18029394597783

---

The Tenant Data report differs from other reports because it includes the customers' addresses and can also be downloaded as a CSV file. You can create similar looking reports by sorting the customer list under the Customer tab however, these lists cannot be downloaded as CSV files. Follow the steps below to navigate to the Tenant Data Report: 

1\. Log in to your account.

2\. Hover over the **Reports** tab and select **All Reports**.

![Capture102.PNG](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5a14989a042863319924a85d/Capture102.PNG)

3\. Click the **Tenant Data** link under the Customer column.

![Capture110.png](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5a14989a042863319924a85e/Capture110.png)

4\. The Tenant Data Report can be formatted for printing as a PDF or downloaded as a CSV file.

![90.png](https://d33v4339jhl8k0.cloudfront.net/docs/assets/5a0382240428633199244fa0/images/5a14989b042863319924a85f/90.png)

When downloading a CSV of all data, the Tenant Data export and the view in the software will **NOT** be changed.

The CSV will**_NOT_** export the username, social security number, Photo ID or security question and answer. The Full Tenant Data export will include the current tenant data report plus the extended information, custom fields, if the customer is tax exempt and the profile notes (found under edit profile). The extended tenant data will not include the notes found at the bottom of the customer's page. The extended tenant data is only available via the export CSV, it is not viewable in the software.
